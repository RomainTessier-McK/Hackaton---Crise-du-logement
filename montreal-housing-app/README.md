# Montréal Rental Housing Affordability — FSA Intelligence

A React app for **Hackathon Theme 2 (Montreal Rental Housing Affordability)**. It turns the
StatsCan 2021 Census FSA profile and the CMHC Rental Market Report 2025 into one analytical
overview plus four product modules mapped to the pitches in the kickoff deck.

## What's inside

| Module | Pitch | Audience | What it does |
|---|---|---|---|
| **Affordability Overview** | Phase 1 analysis | — | KPIs, cost-burden distribution, dual-stress scatter, top-10 stressed table, region comparison, heat grid |
| **STIR-Score Montréal** | Pitch 1 | Renters | Enter FSA + rent + income → STIR badge, rent/income shock sliders, cheaper peer FSAs, printable landlord letter |
| **Subsidy Gap Finder** | Pitch 2 | Ville de Montréal / OMHM | Stress × subsidy quadrant, gap-score ranking, reallocation memo, CSV export |
| **Stress Cluster Alert** | Pitch 3 | FRAPRU / comités logement | Compound vulnerability (cost-burden × chosen demographics), priority ranking, canvassing brief |
| **Rent Pulse Montréal** | Pitch 4 | CMHC / analysts | CMHC zone rent YoY, rent-shock overlay projecting 2025 STIR, zone rent table |

## Run it

```bash
pnpm install
pnpm dev        # http://localhost:5173
pnpm build      # type-check + production build to dist/
```

## Data

`src/data/fsaData.json` is generated by `../build_dataset.py` from:

- `98-401-X2021013_eng_CSV/98-401-X2021013_English_CSV_data_filtered.csv` (Census 2021 FSA profile, long format)
- `rmr-montreal-2025-en.xlsx` (CMHC RMR 2025, Table 1.1.2)

To regenerate:

```bash
python ../build_dataset.py
```

The pipeline pivots the census long-form data to per-FSA metrics, applies an approximate
FSA→CMHC zone crosswalk, and computes derived fields: implied STIR, stress/subsidy/rent
percentiles, gap score, demographic vulnerability index, compound stress, and a dual-stress flag.

## Caveats (shown in-app)

- Census income reflects 2020 and shelter 2021; CMHC rents are Oct 2025 — real-time STIR is higher than shown.
- Income is all-household, not renter-only.
- FSA↔CMHC zone is an approximate neighbourhood crosswalk; the two geographies are not nested.
- Small-sample FSAs (e.g. J7B, H3Y) can be noisy.
